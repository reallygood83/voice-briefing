# Voice Note Obsidian Plugin

Convert your Obsidian notes into shareable audio briefings with AI-powered script generation and cloud sharing.

## Features
- 🎙️ AI-powered voice briefing generation
- 🌐 Multi-language support (Korean, English, Japanese, Chinese, Spanish, French, German)
- ☁️ Google Drive cloud sharing (3-click setup)
- 🎨 Multiple briefing styles (Metaphor, Feynman, News Anchor)
- 🔊 Free & Premium TTS (Edge TTS, ElevenLabs)
